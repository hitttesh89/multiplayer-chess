♟️ Multiplayer Chess Game

A real-time multiplayer chess application where two players can play chess online. The project uses Socket.IO for live communication, Chess.js for move validation and game logic, and EJS for server-side rendering.

🚀 Features
- Real-time multiplayer gameplay
- Automatic White and Black player assignment
- Live board synchronization using Socket.IO
- Chess move validation with Chess.js
- Drag-and-drop piece movement
- Responsive chessboard UI
- Built with Node.js and Express.js
